How this fits claude-design (CLI mode)

Hosted Claude Design panes don’t exist here. The workflow is: brief → context (your tokens) → surface (Operate) → HTML artifact → pick a direction → tighten in repo tokens. File lives at docs/design-mocks/SN_UI_Moodboard.html — open in any browser (double-click or drag into Chrome).

Foundation-safe takeaway

No new layout architecture required. Likely ship path if you like what you see: keep SN grid; retune --radius + borders toward Linear; optional chapter pane (Obsidian) as a density mode; Raycast glow only on focus/cmd/primary CTA — never full-app gradients.
