What “Eclipse” is in SN

UI label Eclipse = theme id midnight-graphite in src/lib/theme-provider.tsx. Same Midnight OLED + violet primary as Midnight, but foreground/muted are neutral greys (--foreground: 0 0% 65%) instead of near-white. These mocks use that palette only.

Hybrid recipe

Structure from Linear (A) or Obsidian (B) + Raycast energy on active rail, ⌘K strip, gradient primary, soft glow — not full-app gradients. Foundation-safe: no new layout architecture required for A; B’s chapter pane would be an optional density mode.
