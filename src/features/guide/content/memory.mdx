# Memory Guide

Factual, concrete facts about your project — proposed by the RAG Scanner or added by you, always reviewed before they're retrievable by anything else.

> [!NOTE]
> This is concrete/factual memory only (established facts, open threads, events, voice rules, project notes, writer preferences) — never psychological or thematic tracking, matching this app's standing scope constraint everywhere else (Codex, Relationships).

---

## 1. The four tabs

_Path: **Memory** in the left sidebar_

| Tab | What it shows |
| --- | --- |
| **Pending** | Newly proposed memories — not yet retrievable by anything until you act |
| **Active** | Approved memories, live in chat/scanner context when opted in |
| **Rejected** | Declined proposals, kept for reference |
| **Superseded** | Prior versions of a memory that's since been revised — read-only history |

Each memory has a category badge (Established Fact, Open Thread, Event, Voice Rule, Project Note, Writer Preference) and, if it came from a scan, a small "via scan" note.

## 2. Adding memories

- **New Note** creates one directly — title, body, category — landing straight in Pending like any other proposal.
- **Suggest memories from this scan** (RAG Scanner tool, on a completed scan) proposes candidate memories from that scan's findings — never auto-chained, always a manual click.

## 3. Reviewing

A **pending** memory gets **Approve** / **Reject**. Anything **pending or active** can be edited in place (Pencil icon) — for a pending row, editing and approving stay two separate actions; for an active row, saving re-indexes it immediately. Only non-pending memories can be deleted.

**Pin** an active memory (pin icon) to guarantee it's always included in chat context whenever Project Memory is switched on — pinned memories sort to the top of the list too.

## 4. Using memory elsewhere

- **Chat context** — any chat's "Context & memory" section has an **Include project memory** toggle (off by default). When on, active memories (pinned ones guaranteed, others via relevance search) are included.
- **Scanner** — the RAG Scanner can read active memory for contradiction checks when opted in per-scan, alongside its own Codex/Timeline checks.

## 5. Troubleshooting

| Problem | What's happening |
| --- | --- |
| A memory I approved isn't showing up in chat | Check the chat's own "Include project memory" toggle — it's off by default per chat |
| I can't delete a memory | Pending memories can only be Approved or Rejected first — deletion is for non-pending rows only |
| "Suggest memories from this scan" isn't visible | It only appears on a **completed** scan in the RAG Scanner tool |
| An old version of a memory I edited disappeared | It moved to the **Superseded** tab, not deleted — a revised active memory keeps its prior version there as read-only history |

---

Memories save with your story like any other data. Approving/rejecting/pinning all take effect immediately, no separate publish step.
