# Locations & Maps

Location entries in the Lorebook get their own guided setup script, a lightweight "place sheet" of structured details, a sketch-canvas **Maps** tool for actually drawing a place, and — if you need it — the same versioned Codex tracking Character entries use.

> [!NOTE]
> None of this is required. A location entry works exactly like any other Lorebook entry if you never touch these features — they're opt-in layers on top.

---

## 1. Location Guided Setup

World-Building chats opened on a **Location** template walk through a focused interview script — scale, biome, who/what controls the place, danger level, notable landmarks, exits, layout, and a one-line image brief — the same "Light / Standard / Grill-me" depth control every Guided Setup chat has.

## 2. The Place Sheet

Every location entry has a **Place sheet** section in its editor — *"A lightweight structured summary — not tracked Codex state. Fill in whatever's known; the rest can come from a World-Building chat later."* Fields: **Scale**, **Biome / climate**, **Holder**, **Danger level**, **Floor** (for nested locations, e.g. "2F"), **Landmarks**, **Exits summary**, **Layout** (markdown/ASCII), and **Image brief**.

You can fill these in by hand, or a World-Building chat can propose them for you — they show up as a card you Accept or Reject before anything is saved, same as every other chat proposal in this app.

> [!TIP]
> The **Image brief** field feeds the **Map** image preset (alongside the usual **Mood** preset) when generating a location's image — it produces a top-down/reference-style image instead of a mood illustration.

## 3. Maps — sketch canvases

_Path: **Maps** in the left sidebar_

A hand-drawn, boxes-and-labels sketch canvas — a safehouse floor plan, a city, a whole continent, whatever scale you need. This is a different job from **Relations** (which tracks factual/social connections between any two entries) — Maps is for actually drawing a place.

**Maps** opens on a list of the story's sketch maps. **New map** creates one — either a free-standing story map (not tied to any location, good for a "front lines" theater map or anything that doesn't map to a single Lorebook entry) or one linked to an existing location. A location entry's own editor also has an **Open map** button: it opens that location's linked map, or creates one on the spot if it doesn't have one yet.

Click into a map to reach the canvas itself — a full [Excalidraw](https://excalidraw.com)-based sketch tool: rectangles, ellipses, diamonds, arrows, lines, freehand drawing, and text, with native undo/redo (Ctrl+Z / Ctrl+Shift+Z, or the toolbar buttons). Everything autosaves as you draw — there's no save button.

At the top of a map's canvas:

| Button | What it does |
| --- | --- |
| **Export to place sheet** (location-linked maps) / **Copy as text** (free maps) | Summarizes the current sketch as a short text list (what's on the canvas, roughly top-to-bottom) — either written into the linked location's **Layout** place-sheet field, or copied to your clipboard |
| **Download PNG** | Saves the current sketch as an image — an illustration only, never re-imported as the map's real data |
| Trash icon | Deletes the map (and its sketch) permanently |

> [!TIP]
> If a location already has text in its **Layout** place-sheet field (see §2 above) when you first open its (still-empty) linked map, you'll be offered a one-time **Convert to sketch** choice — it drops that existing text onto the canvas as a starting point rather than making you retype it. Choosing **Start blank canvas** instead just skips it for now; the offer reappears next time you open that same still-empty map, so nothing is lost either way.

### AI-sketched maps

A location's own World-Building chat can propose a sketch for you — ask in plain language ("sketch the safehouse: entry hall, bolt-hole, alley exit") and, if it has enough to go on, the reply includes a **Sketch map** card summarizing what it drew (title, element count, a short preview). **Accept** creates (or replaces the sketch on) that location's linked map and takes you straight to the canvas so you can nudge things into place; **Reject** discards it. Accepting **replaces the entire current sketch** — the AI proposes a whole scene, not a patch, so accept a proposal only when you're fine starting over from it. This only works for location-linked maps (a chat needs something to anchor to); free story maps don't have an AI-propose option.

> [!NOTE]
> If the Maps list is empty for a story, that's normal — sketch maps don't exist until you create one (via **New map**, or a location's **Open map** / an AI sketch proposal's Accept). Nothing is auto-generated from your Lorebook entries.

## 4. Tracking Full Place-Codex State

For locations that matter enough to need real edit history — the way Character entries already do — flip **Track Place State** on a location entry. This promotes its place sheet into the same versioned system Character Codex uses: full snapshot history, and any future chat-proposed place-sheet changes go through the normal Approve / Reject / Edit-First review instead of applying immediately.

## 5. Troubleshooting

| Problem                                        | What's happening                                                                          |
| ------------------------------------------------ | --------------------------------------------------------------------------------------------- |
| Maps list is empty                                | Normal until you create a map — nothing is auto-generated from Lorebook entries; use **New map** or a location's **Open map** |
| "Export to place sheet" / "Copy as text" says nothing to export | Draw something on the canvas first — an empty sketch has nothing to summarize |
| A sketch proposal's Accept overwrote my drawing   | Accepting an AI sketch proposal always replaces the map's entire current sketch, by design — the card's own text warns about this before you click Accept |
| Place sheet changes didn't take effect right away | Check whether **Track Place State** is on — once it is, changes go through Approve/Reject like Character Codex, they don't apply instantly |
| "Track Place State" switch seems to do nothing at first | It only affects future place-sheet edits (manual and chat-proposed) — existing values are carried over automatically |

---

Place sheets, Track Place State, and sketch maps all save to your story like any other Lorebook data — no separate export step needed beyond the normal story export (which includes your maps' sketches).
