# Research Guide

A dedicated web-research desk — live search and page-fetch, kept separate from your Lorebook/Codex/Outline so browsing the web never accidentally becomes canon.

> [!NOTE]
> Research never proposes Codex entries, outline items, or prose. It's read/cite only — anything worth keeping, you save yourself (as a note, or via Chat Shuttle back to wherever you started).

---

## 1. Story vs. Global mode

_Path: **Research** in the left sidebar_

| Mode | What it is |
| --- | --- |
| **Story** | Bound to your current story — light story seasoning (title + synopsis) plus opt-in Notes/Lorebook context, own chat list per story |
| **Global** | Pure web research, not tied to any story — its own separate chat list, available even with no story open |

Each mode is a genuinely separate set of chats (its own "most recent or create a new one" rail), not a toggle on one shared conversation — switching modes switches which chat list you're looking at.

## 2. Searching and citations

Just ask — Research fires a live web search (DuckDuckGo, no API key required) based on your actual message text, then can fetch and summarize specific pages it finds. Citation links in replies open in a new tab.

## 3. Context & memory

The **Context** panel (sliders icon) offers the same opt-in toggles most chats get — in Story mode, that includes Notes and Lorebook; the panel is unavailable until a chat exists.

## 4. Chat Shuttle

Other chats (Editor, World-Building, Outline) can propose shuttling a real-world-fact question out to Research rather than answering it themselves — opening that shuttle lands you in Research's Story mode with the question pre-seeded into the composer, and a **"Shuttled in from another chat"** banner offering **Send brief to origin**: posts the latest reply (summary + any citation links) back to the origin chat's own tray, without auto-injecting anything into that chat's transcript. You can send a brief back more than once as the conversation continues.

## 5. Troubleshooting

| Problem | What's happening |
| --- | --- |
| Story mode tab is disabled | No story is currently open — open one, or stay in Global mode |
| A search came back empty | DuckDuckGo's HTML search occasionally returns nothing for a query — try rephrasing |
| "Send brief to origin" isn't showing | It only appears once you've arrived via a Chat Shuttle handoff — a chat you started directly in Research has no origin to send back to |
| Research proposed something into my Lorebook | It shouldn't — Research has no Codex/outline/prose write path by design; if you're seeing this, something else in your workflow (e.g. a copy-paste into another chat) is responsible |

---

Research chats save with your story (Story mode) or your account (Global mode) like any other chat data.
