# Outline Guide

Plan your story's structure before (or alongside) writing it: chapters containing nested scenes, each with a title, a concrete summary, and a word count target — separate from the per-chapter free-text outline field you may already know from the Main Editor's **Outline** drawer, which is unrelated and untouched.

> [!NOTE]
> This is a story-wide _planning_ layer, not your chapter prose. An outline "chapter" can optionally correspond to a real chapter you've already written, or it can exist purely as a plan for something you haven't written yet.

---

## 1. Building the Outline

_Path: **Outline** in the left sidebar (requires a story to be open)_

- **Add Chapter** creates a new top-level entry with a title, summary, and optional word count target.
- Click the **+** icon on a chapter to add a **scene** nested underneath it.
- Drag the grip handle on the left of any row to reorder — chapters reorder among chapters, and scenes reorder among their own chapter's other scenes.
- To move a scene to a _different_ chapter, use the small chapter dropdown on the right of its row instead of dragging — this keeps a scene's own reordering simple while still letting you restructure freely.
- Click the pencil icon to edit a chapter or scene's title, summary, or word count target. The trash icon deletes it — deleting a chapter also deletes its scenes.

## 2. Character Arc Tracking

Link any chapter or scene to one or more characters from your Lorebook using the small person icon next to its character chips. Each link can carry a short note about that character's development at that specific point in the story.

Switch to the **Character Arcs** tab and pick a character to see every outline item they're linked to, in story order, with their notes — this ordered list _is_ their arc overview. Click any note to edit it.

> [!TIP]
> Keep arc notes concrete ("loses the locket in the chase," not "grows more vulnerable") — the same "observable, not thematic" bias the rest of this app's tracking features (Concrete Beats, Character Codex) use throughout.

## 3. AI-Assisted Outlining

Outline has its own dedicated chat (icon rail on the right, same shell every chat-hosting tool uses) rather than a single bulk "generate" button — talk through structure, and the model proposes chapters/scenes as it goes, using your story's synopsis, characters, and existing outline as context.

- **New chapters/scenes** the model proposes are persisted immediately as pending entries — each appears in the tree with a dashed amber border and an "AI Suggested" badge, exactly like before:

  | Action | What it does |
  | --- | --- |
  | **Accept** (✓) | Confirms this one item, making it a normal outline entry |
  | **Edit** (pencil) | Opens the same edit dialog as any other item — doesn't accept it |
  | **Reject** (✗) | Discards this one suggestion |
  | **Reject All Suggestions** | Discards every pending suggestion for the story at once |

  Accepting a suggested chapter does **not** automatically accept its suggested scenes — each is reviewed independently.

- **Edits, reorders, and deletes** the model proposes appear as a card directly in the chat reply instead, with its own Accept/Reject — nothing changes in your outline until you click Accept.
- **Lore suggestions** — if the conversation surfaces something that sounds like a new character/location/etc., it appears in the Approvals panel as a card with **Open in WB**. This seeds a draft entry in the Lorebook tool; Outline never creates entries directly.

Every row also has its own **Rework in chat** button (pencil-in-bubble icon) — send just that chapter or scene's title/summary into the Outline chat for a targeted rewrite, without describing the whole outline from scratch.

### Outline Import

Attach a structure document (PDF/DOCX/MD/TXT) via the paperclip button above the composer, or the **Import structure document…** card next to the chat list. The model extracts a chapter/scene draft, shown in an editable panel before anything touches your real outline:

- If your outline is currently empty, the draft extracts immediately.
- If you already have outline items, you're asked whether to **Append** after them or **Replace all** (Replace is a hard, confirmed action).
- The draft can also surface **cast mentions** (characters it noticed in the source document) and **arc notes** — reviewed the same Accept/Reject way, with an option to link an accepted cast mention to the character chip on its outline item once the batch itself has been accepted.

## 4. Troubleshooting

| Problem                                                  | What's happening                                                                                          |
| -------------------------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| "No AI provider configured" in the Outline chat          | Set up a model in Settings → Providers & keys (or a Local connection) — the Outline chat uses your global default unless you've routed it elsewhere in Feature routing |
| A character shows "Character removed" on a chip          | The linked Lorebook entry was deleted — unlink it if you no longer need the reference                     |
| The "Move to chapter" dropdown doesn't appear on a scene | It only shows when there's more than one chapter to move to                                               |
| Import asked Append vs. Replace and I want to redo it    | Replace All wipes every existing outline row and link first — make sure that's really what you want before confirming |

---

Outline items persist in your local database alongside the rest of your story data — no account or cloud sync required, and creating/reordering/linking all work fully offline. Only the Outline chat and Outline Import need a reachable model endpoint.
